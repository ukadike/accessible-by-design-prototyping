Website Check

Use the GitHub audit to check public websites in a fresh browser, or use the bookmarklet to check the page already open in your browser. Automated results can miss content and usability problems, so manual review still matters.

Results are grouped by what they affect: page structure, images and media, links and buttons, forms, color and contrast, keyboard access — plus recommendations only a person can check.

Option 1: Check a website through GitHub

GitHub Actions opens the public website in Chromium and runs the accessibility check on the rendered page. It does not rely on a cross-site relay.

  1. Open the website audit workflow below.
  2. Choose Run workflow and enter one or more public website addresses, one per line.
  3. When the run finishes, download the Markdown and JSON report from its artifacts.

Open the GitHub website audit

Requires GitHub sign-in and permission to run workflows in this repository. The report contains audit findings, not a copy of the website.

Option 2: Check the page in your browser

  1. Drag this button up into your browser's bookmarks bar:

    Audit this page

    Can't see your bookmarks bar? Press Ctrl+Shift+B (or ⌘+Shift+B on a Mac) to show it.

  2. Go to the website you want to check — for example, your own site.
  3. Click the Audit this page bookmark. The check runs on the page you are viewing.
If nothing happens when you click the bookmark

Some websites have strict security settings that block bookmarklets. If your results don't appear, try the GitHub website audit above, or ask whoever builds your website to run the developer version of this tool.
